# SaaS IA y stack local — ampliación editorial

Fecha: 2026-06-04

## Fuentes oficiales revisadas

- OpenAI Codex: agente de código para leer, editar, ejecutar y verificar cambios.
- OpenAI Codex for every role: uso de Codex para apps internas, dashboards, investigación y flujos no estrictamente dev.
- Anthropic Claude Code: agente terminal que lee codebases, ejecuta comandos, usa MCP y trabaja de forma iterativa.
- OpenRouter Models API: catálogo y metadatos/precios para cientos de modelos mediante una API.

## Lectura editorial

La sección SaaS IA debe enseñar a convertir herramientas en productos, no solo listar herramientas.

Patrones iniciales:

- copiloto vertical;
- automatización de backoffice;
- benchmark como producto;
- agente de investigación;
- RAG privado;
- generación de informes;
- monitor de novedades IA.

Cada idea debe incluir problema, usuario, MVP, stack, riesgo y prompt inicial para construir con agente de código.
