# Guías de compra y herramientas IA

Fecha: 2026-06-04

## Objetivo

Separar dos decisiones que suelen mezclarse:

- qué hardware comprar;
- qué herramienta usar para construir.

## Nuevas secciones

- Guías de compra: portátiles, Mac, NVIDIA, AMD, workstations, dispositivos con IA.
- Herramientas IA: Codex, Claude Code, OpenRouter, Lovable, Cursor/Replit, Ollama, LM Studio, llama.cpp, MLX, vLLM, SGLang.

## Regla editorial

Cada guía debe terminar con una prueba mínima reproducible. Si no se puede medir, no se recomienda.
